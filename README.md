# 涟漪实验室 · React 前端

本地多实验社交媒体传播仿真工作台。当前使用明确标记的演示数据，未连接远程服务器、vLLM 或真实仿真引擎。

## 启动

```sh
npm install
npm run dev -- --port 5173
```

访问 http://127.0.0.1:5173/ 。生产构建使用 `npm run build`。

## 已有功能

- 工作区标签栏：模块、事件详情、实验详情和新建实验可以同时打开，支持切换与关闭。
- 每个页面都有“工作区 / 模块 / 当前对象”面包屑路径。
- 新建实验使用独立完整页面，不使用弹窗。
- 创建多个独立实验，选择目标事件、背景数量与调度方式。
- 时间步、人群数量、浏览容量、随机种子等基础参数。
- 草稿、排队、运行、暂停、停止、完成的状态管理。
- 可配置并行槽位，按提交顺序启动，暂停或完成后释放槽位。
- 五个阶段的步骤进度、独立日志、配置与日志下载。
- 目标事件示意网络、时间轴播放、独立事件快照导出。
- 事件示例库及真实对比页面样例。
- 当前浏览器 localStorage 保存配置和运行进度，刷新后恢复。

模块职责：

- `我的实验`：实验资产、配置和版本入口，不提供进程控制。
- `进程管理`：运行槽位、等待队列、暂停、继续与停止。
- `事件库`：事件检索、事件资料和目标事件入口。
- `验证中心`：已完成实验的结果入口。
- `新建实验`：独立配置流程，完成后生成实验草稿。

## 后续接入

`src/AppShell.jsx` 管理当前的标签页、页面路由、前端演示状态与调度。后续应由后端管理长时运行和状态持久化，前端通过接口订阅进度。关闭浏览器后演示任务不会继续推进。

当前 `NetworkMap` 为示意图，时间轴只演示回放交互；验证曲线和指标均为固定样例。vLLM 调用、Agent 画像、真实传播状态与数据导入留待后续实现。
